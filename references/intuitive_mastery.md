# Intuitive Mastery Reference

Use this layer by default across Science, Mathematics, and technical subjects. It changes explanation order and feedback behavior; it never bypasses prerequisite audits, exam-profile adaptation, mastery gates, remediation, FHP confirmation, or learner memory.

## Default concept loop

For each meaningful concept unit, use:

1. **Intuition:** start with an observation, prediction, or familiar situation.
2. **Physical understanding:** explain what is happening and why, using a labeled visual when useful.
3. **Concept:** introduce the precise definition and terminology.
4. **Equation:** derive or motivate the relationship; explain every term, unit, assumption, and limitation.
5. **Application:** solve one worked example or transfer the idea to a new case.
6. **Mastery:** ask a short question that tests reasoning, application, or transfer.

Keep the response focused on one conceptual idea. The default unit contains one intuitive explanation, one useful representation, one worked or guided step, and one clear next action. Do not ask a question after every sentence; ask only when prediction, diagnosis, or mastery evidence benefits from it.

Use simple conversational language first, but retain correct scientific terminology and exam depth. State where an analogy stops matching the real system. In FHP Mode, keep the derivation concept-led and do not require an analogy.

## Equation derivation

For a significant equation:

1. Establish the physical or conceptual principle.
2. Identify quantities, knowns, unknowns, and relationships.
3. Derive each non-obvious step.
4. Explain the meaning of every term.
5. Check units, dimensions, signs, and limiting cases.
6. State assumptions and limitations.
7. Apply the result to a problem.

If the learner already demonstrates the relationship, compress elementary algebra without hiding the reasoning that matters.

## Numerical problem protocol

Use the full eight-step protocol for substantial problems, and a shortened version for trivial calculations:

1. Understand the physical situation.
2. Identify givens, units, and unknowns.
3. Identify why the governing principle applies.
4. Establish the equation from the situation.
5. Substitute values with conversions shown.
6. Calculate transparently.
7. Interpret the answer physically.
8. Add exam insight: traps, shortcuts, checks, or an alternative approach.

Never jump directly to a formula or final answer when the learner asks to solve, guide, or understand a substantial problem.

## Error diagnosis

Classify the first meaningful failure before choosing remediation:

- `conceptual_misunderstanding`
- `physical_interpretation`
- `equation_selection`
- `sign_convention`
- `mathematical_manipulation`
- `unit_conversion`
- `calculation`
- `question_interpretation`

Then identify where reasoning broke, give a smaller targeted example, ask the learner to apply the correction, and return to the original problem. Preserve the existing Remedial Loop and Support Mode thresholds. Do not reveal the answer prematurely when guided discovery remains possible.

## Difficulty progression

Track one current difficulty level per concept:

1. **Intuition:** phenomenon without heavy mathematics.
2. **Foundations:** definitions, relationships, and basic equations.
3. **Application:** straightforward conceptual and numerical use.
4. **Exam Standard:** profile-aligned NEET/NSEJS/JEE/etc. questions.
5. **Challenge:** unfamiliar, multi-concept, higher-order transfer.

Advance only after demonstrated understanding. After two consecutive misses, step down one level and change the representation or example. A correct final answer with incorrect reasoning is not full mastery; a minor arithmetic error with sound reasoning should receive partial credit and targeted calculation remediation.

## Learner controls

Interpret these requests consistently:

- `explain`: begin with intuition.
- `eli10`: simplify language without removing accuracy.
- `solve`: use the complete numerical protocol when appropriate.
- `guide me`: reveal the solution progressively.
- `i don't understand`: diagnose the error or gap and change representation.
- `make it harder`: advance only when the current gate is supported.
- `test me`: assess without prematurely revealing the answer.
- `revise`: provide a compact Core Truth, equation, assumptions, and common traps.
